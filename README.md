# 🛍️ OOP Ecommerce

Учебный проект для отработки объектно-ориентированного программирования на примере интернет-магазина.

---

## 📦 Классы

### 📱 Product (Товар)

| Атрибут | Тип | Описание |
|---------|------|-------------|
| `name` | `str` | Название товара |
| `description` | `str` | Описание товара |
| `price` | `float` | Цена товара |
| `quantity` | `int` | Количество в наличии |

**Исключение:** при создании товара с `quantity = 0` выбрасывается `ValueError`:


### 📂 Category (Категория)

**Атрибуты экземпляра:**

| Атрибут | Тип | Описание |
|---------|------|-------------|
| `name` | `str` | Название категории |
| `description` | `str` | Описание категории |
| `products` | `List[Product]` | Список товаров в категории (приватный) |

**Атрибуты класса:**

| Атрибут | Тип | Описание |
|---------|------|-------------|
| `category_count` | `int` | Общее количество категорий |
| `product_count` | `int` | Общее количество товаров |

**Методы:**
- `add_product(product)` — добавляет товар в категорию
- `average_price()` — возвращает средний ценник всех товаров в категории (0.0 для пустой категории)

## 🧪 Тестирование

```bash
# Запуск всех тестов
pytest tests/ -v

# Проверка стиля кода
flake8 src/ tests/

# Проверка типов
mypy src/

# Отчёт о покрытии
pytest --cov=src --cov-report=html
```

## 🚀 Установка и запуск
```
# Установка зависимостей
poetry install

# Активация виртуального окружения
poetry shell

# Запуск тестов
pytest tests/ -v

# Запуск основной программы
python main.py
```
