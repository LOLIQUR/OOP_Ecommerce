# 🛍️ OOP Ecommerce

Учебный проект для отработки объектно-ориентированного программирования на примере интернет-магазина.

---

## 📦 Классы

### 📱 Product (Товар)

| Атрибут | Тип | Описание |
|---------|------|-------------|
| `name` | `str` | Название товара |
| `description` | `str` | Описание товара |
| `price` | `float` | Цена товара |
| `quantity` | `int` | Количество в наличии |

### 📂 Category (Категория)

**Атрибуты экземпляра:**

| Атрибут | Тип | Описание |
|---------|------|-------------|
| `name` | `str` | Название категории |
| `description` | `str` | Описание категории |
| `products` | `List[Product]` | Список товаров в категории |

**Атрибуты класса:**

| Атрибут | Тип | Описание |
|---------|------|-------------|
| `category_count` | `int` | Общее количество категорий |
| `product_count` | `int` | Общее количество товаров |

## Абстрактный класс и миксин

### BaseProduct (абстрактный класс)
- Определяет общий интерфейс для всех продуктов
- Содержит абстрактные методы `__str__` и `__add__`

### LogMixin (миксин)
- Автоматически логирует создание объектов
- Выводит в консоль информацию о классе и параметрах

### Пример использования
from src.product import Product, Smartphone, LawnGrass

# При создании объекта автоматически выводится лог
phone = Smartphone("Samsung", "Флагман", 180000, 5, "Высокая", "S23 Ultra", 256, "Серый")
# Вывод: Создан объект Smartphone с параметрами: ...
